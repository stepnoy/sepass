#+TITLE: Сборка и проверка SE Pass AutoFill
#+DATE: 2026-10-02

* Состояние реализации
Ветка: feature/secure-enclave-autofill. PR не открыт.
Реализованы системный Credential Provider, список/поиск, старые и новые callbacks
AuthenticationServices, запрос биометрии при расшифровке, индекс доменов,
публикация шифротекстов и отзыв общего доступа. Это MVP только для чтения.

* Сборка
Требуются Xcode с установленными iOS SDK и компонентами, Apple Developer Team
и профили с App Groups, Keychain Sharing и AutoFill Credential Provider.
В App/LocalSigning.xcconfig (игнорируется Git) укажите собственные значения:

#+begin_src conf
DEVELOPMENT_TEAM = YOUR_TEAM_ID
SEPASS_BUNDLE_ID = com.yourname.sepass
APP_GROUP_IDENTIFIER = group.com.yourname.sepass
#+end_src

App/AutoFill.xcconfig формирует Bundle ID расширения и общую Keychain group.
Оба target должны подписываться одной командой и иметь одну App Group.
Не удаляйте приватную Keychain group из entitlements основного приложения.

#+begin_src sh
open App/SEPass.xcodeproj
swift test
xcodebuild -project App/SEPass.xcodeproj -scheme SEPass \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/sepass-derived CODE_SIGNING_ALLOWED=NO build
xcodebuild -project App/SEPass.xcodeproj -scheme SEPass \
  -destination 'generic/platform=iOS' \
  -derivedDataPath /tmp/sepass-device CODE_SIGNING_ALLOWED=NO build
#+end_src

На устройстве нужна подписанная сборка из Xcode, а не CODE_SIGNING_ALLOWED=NO.
Установка форка под новым Bundle ID не переносит ключ App Store версии.

* Подготовка тестовых данных
1. Установить форк на тестовый iPhone, сгенерировать в нём отдельный ключ.
2. Добавить его публичный ключ получателем отдельного тестового pass/prs store.
   Не использовать рабочие секреты для первого испытания.
3. Создать example.com/alice.gpg, зашифрованный тестовому ключу телефона;
   содержимое: первая строка пароль, следующая строка login: alice.
4. Проверить обычную расшифровку в SE Pass, затем включить переключатель
   AutoFill. Перейти в системные настройки AutoFill и выбрать SE Pass.
5. Вернуться в приложение, нажать Refresh AutoFill. В Safari открыть тестовую
   форму входа на соответствующем домене, выбрать SE Pass и запись.

Публикация не расшифровывает все записи: наличие записи в списке ещё не означает,
что её получатели включают ключ этого устройства.

* Аппаратная приёмка: обязательна до использования настоящих секретов
- В списке провайдеров iOS виден SE Pass, расширение запускается из Safari.
- Выбор записи возвращает правильный login и пароль после Face ID/Touch ID.
- QuickType запускает интерактивное подтверждение; без него пароль не выдаётся.
- Отмена Face ID, неверная биометрия и Cancel не заполняют форму. Повтор работает.
- Для другого домена требуется отдельное подтверждение, совпадение подстроки
  и похожие Unicode-домены не считаются совпадением.
- После блокировки и перезагрузки доступ соответствует защите Keychain/файла.
- Отключение AutoFill, удаление ключа/данных или смена remote/branch отзывают
  доступ; старые подсказки не позволяют получить пароль.
- Смена биометрического набора проверяется только на тестовом ключе: существующая
  политика biometryCurrentSet может навсегда лишить его доступа.
- Проверить запись с двумя OpenPGP-получателями: телефон и резервный ключ.
- Отдельно подтвердить, что extension может выполнить ECDH ключом Secure Enclave,
  созданным основным приложением. Проверка компилятором этого не доказывает.

* Ограничения MVP
- Только чтение и ручной выбор/поиск. Нет создания, Git push, passkeys, TOTP AutoFill.
- Индекс содержит домены из компонентов пути и метку имени файла. Содержимое
  login:/url: ради индекса не расшифровывается. Поддомены сопоставляются точно.
- Смена репозитория, импорт папки и замена ключа отключают AutoFill; после
  проверки нового содержимого пользователь включает его заново.
- Симлинки и скрытые файлы/каталоги исключены. Лимиты: 1 MiB на запись,
  16 MiB шифротекстов, 24 MiB JSON, 10 000 записей, путь до 4096 байт/128 уровней.
- Нет обещания работы крупных снимков на всех устройствах: расширение имеет
  ограниченную память; необходимы испытания на целевых iPhone.
- В редкой гонке обновления iOS может кратко показать старую подсказку.
  UUID поколения не даст использовать её для другой версии хранилища.
